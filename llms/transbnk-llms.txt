# TransBnk (TBX)

> TransBnk — rebranded as TBX — is an Indian open-finance and transaction-banking
> infrastructure company (founded 2022, Mumbai). It provides banks, enterprises,
> fintechs, corporates, and NBFCs with the platforms, APIs, and connected
> workflows behind corporate banking: mandate management, escrow flows, virtual
> accounts, reconciliation, lending acceleration, and cash/treasury management.
> The company reports 25+ bank partnerships, 200+ APIs extended, 100+ BFSI
> clients, and 50M+ transactions processed.

## Products
- TxB Hub — transaction banking platform (mandates, escrow, reconciliation).
- TrustHub — core banking / trust-and-escrow platform.
- API Hub — the API integration surface for partner banks and fintechs (login-gated).

## Segments
- For Banks: modernized transaction banking with mandate management, escrow flows, and reconciliation.
- For Lenders: lending acceleration via onboarding, automated escrows, and repayment intelligence.
- For Corporates: unified cash, treasury, and payment management.
